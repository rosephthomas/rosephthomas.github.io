Help & Instructions

This app allows you to record fiber optic cable data points with GPS coordinates for location correlation.

  • Project Name: Name your project. This will appear in export filenames.
  • Data Fields: Fiber Count, Cable Brand, Serial Number, Footage Mark, Date Stamp are all optional. Enter what is visible.
  • Record / Add Location: Tap this button to save the current data with GPS coordinates. GPS is required and the app will keep prompting if unavailable.
  • Editing: You can edit or delete any record. Editing preserves GPS location unless you press "Recapture Location".
  • Export Data: Exports a ZIP file containing a CSV and a KML file with your recorded data. Filenames are timestamped and use the project name.
  • Clear All: Clears all saved records after confirmation.
  • Light/Dark Theme: Toggle between light and dark modes for a clean, matte paper look.
  • Coordinates are rounded to 4 decimal places (~30 feet accuracy).

The app stores your data locally in the browser, so data won't be lost if you reload or close and reopen the page.

Works offline after first load. Compatible with Android, iPhone, and desktop browsers.
