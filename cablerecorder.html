Help & Instructions

This app allows you to record fiber optic cable data points with GPS coordinates for location correlation.

  • Project Name: Name your project. Persists across entries and appears in export filenames.
  • Strip Spaces Option: When checked, all whitespace will automatically be removed from recorded serial numbers.
  • Data Fields: All form fields persist across entries so you can log progressive footage marks quickly without re-entering unchanged cable attributes.
  • Record / Add Location: Tap this button to save the current data with GPS coordinates.
  • Editing: You can edit or delete any record. Editing preserves GPS location unless you press "Recapture Location".
  • Export Data: Exports a ZIP file containing a CSV and a KML file with your recorded data.
  • Clear All: Clears all saved records after confirmation.

The app stores your data locally in the browser, so data won't be lost if you reload or close and reopen the page.
